## Project Evidence

Screenshots and experimental outputs are included in the repository to document the research workflow, dataset preparation, object-detection experiments, and model evaluation.

The available evidence includes Roboflow dataset views, annotation examples, training graphs, validation outputs, and detection visualizations. Some screenshots may belong to separate football experiments, so results are not attributed to the pickleball project unless verified.

The project remains research-oriented and is not presented as a fully deployed automated tracking and scoring system.
